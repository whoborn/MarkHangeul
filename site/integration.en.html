This independent preview accepts Markdown source. It uses only the SDK, without loading the editor application.

Preparing the SDK…

1. Embed a Web Component

<script type="module"
  src="https://whoborn.github.io/MarkHangeul/sdk/markhangeul.js">
</script>
<mark-hangeul source="마{T2}"></mark-hangeul>

For live input, assign element.source = editorValue. Shadow DOM isolates the component's styles from the host page.

2. Connect an editor's preview function

import { init, renderMarkdown, parse } from
  'https://whoborn.github.io/MarkHangeul/sdk/markhangeul.js';
await init();
preview.innerHTML = renderMarkdown(editor.getValue());
console.log(parse(editor.getValue()).errors);

When using the function API, load sdk/markhangeul.css separately. Pass Markdown source, not HTML generated by another Markdown converter. The parser processes the source while preserving code, links and tables.

Editors such as Obsidian and VS Code require a host-specific plugin that calls this API. We do not currently provide installable plugins for those editors. GitHub README pages do not execute scripts; use static examples and links to the live editor instead.

3. Host the files yourself

Download the static site and SDK ZIP and deploy the complete sdk/ folder. Keep the JavaScript and WASM files from the same build together. Serve them over HTTP(S), with the WASM MIME type set to application/wasm.

For reproducible versions, build a verified commit and host it yourself. The Pages SDK URL changes with each deployment. No npm or CDN package registration is implied.
